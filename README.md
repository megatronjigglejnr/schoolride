# SchoolRide

The parent app prototype for SchoolRide: live school-transport tracking that schools license for their families. It's plain HTML, CSS and JS, and it's the design and behaviour reference for the React Native app to come.

## Run it

Open `app/index.html` in a browser, or:

```bash
npm start            # http://localhost:5173
```

## Test it

```bash
npm run setup        # once: Playwright + Chromium
npm test             # behaviour, contrast, tap targets and layout checks
```

## Working with Claude Code

Open this folder in Claude Code. `CLAUDE.md` gives it the context it needs: how the app is built, which decisions are settled, the quality bar, and what's next. The product and design background is in `docs/`.
